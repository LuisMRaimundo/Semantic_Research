# OEWN local archives

Runtime uses the Python `wn` pin from `config.toml` (`oewn:2025`), with
companions `oewn:2024` and `oewn:2025+` kept installed.

Optional dump files (WNDB / WN-LMF) may be downloaded here for offline
archive; they are gitignored. Official sources:

| File | URL |
|------|-----|
| 2024 WNDB | https://en-word.net/downloads/english-wordnet-2024.zip |
| 2024 XML | https://en-word.net/downloads/english-wordnet-2024.xml.gz |
| 2025 WNDB | https://en-word.net/downloads/english-wordnet-2025.zip |
| 2025 XML | https://en-word.net/downloads/english-wordnet-2025.xml.gz |
| 2025+ WNDB | https://en-word.net/downloads/english-wordnet-2025-plus.zip |
| 2025+ XML | https://en-word.net/downloads/english-wordnet-2025-plus.xml.gz |
