# CONTO.PT (source dumps)

Fuzzy Portuguese wordnet family from Universidade de Coimbra / Onto.PT project:

| Folder | Resource | Role |
|--------|----------|------|
| `CONTO.PT.01/` | CONTO.PT 0.1 | ~34k fuzzy synsets + confidence-weighted relations |
| `clip21/` | CLIP 2.1 | ~20k fuzzy membership synsets |

**Runtime:** already loaded in `engines/ONTO/ontopt.sqlite` as `contopt` and `clip21`
(searched from the workbench via **Onto.PT / CONTO.PT**). These folders are the
official source archives for provenance / rebuild — not a second parallel engine.
